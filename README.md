# GitHub Documentation App

Web app that generates documentation for GitHub projects.

## Features

- Next.js App Router
- Tailwind UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/github-documentation.git
cd github-documentation
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
